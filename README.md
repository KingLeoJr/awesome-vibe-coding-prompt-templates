## ✨ What is this?

This repository contains:

- **Complete file/folder structures** for **every** prompt in the original [KingLeoJr/prompts](https://github.com/KingLeoJr/prompts) repository (46+ applications)
- A clean **Entity-Relationship Meta-Model** approach so every building component is parameterized
- Ready-to-use `.template` files that a generic generator can populate from configuration values
- Designed for **Model-Driven Development** + AI coding agents

From a single user request → configuration values are generated → templates are filled → you get a complete, customized project ready for Cursor / Bolt / Lovable / etc.

## 🎯 Why this exists

Most prompt libraries give you a long list of requirements.  
This project goes one level deeper:

1. Uncovers every **building component** of the application
2. Models them as a proper **parameterized ER Meta-Model**
3. Provides actual **template files** (React, Astro, Next.js, Vue, WordPress, etc.)
4. Enables a future generic/genetic generator to create fully customized projects from a simple user request

---

## 🛠️ How to use

1. Choose the structure you need
2. (Coming soon) Feed a natural language request into the configuration engine
3. The instance generator populates all `.template` files with your values
4. Drop the resulting project into Cursor, Bolt.new, Lovable, Windsurf, Cline, or Aider and let the AI build it
